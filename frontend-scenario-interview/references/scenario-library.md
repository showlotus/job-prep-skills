## 1. 性能优化场景

### 场景题：大屏组件过多导致页面卡顿
- **描述**：大屏如果拖的组件太多，导致页面卡顿，如何解决，以及如何分析，可以借助哪些工具去分析
- **追问方向**：性能分析工具使用、内存分析、渲染性能优化策略

### 场景题：大屏多图表各自更新性能优化
- **描述**：大屏中多个图表各自更新（各自按照自己的更新间隔进行更新），如何提升性能
- **追问方向**：定时器管理、批量更新策略、节流防抖应用

### 场景题：长函数执行耗时优化
- **描述**：如何优化一个长函数（执行很耗时的函数）
- **追问方向**：算法优化、Web Worker、任务分片、时间切片

### 场景题：首屏加载优化全流程
- **描述**：从浏览器输入一段 URL 到页面加载出来，中间有什么可以优化的地方
- **追问方向**：DNS 优化、缓存策略、资源压缩、懒加载、CDN 使用

### 场景题：Vue3 性能优化手段
- **描述**：在使用框架（Vue）中，有没有借助框架进行一些性能优化；Vue3 性能提升主要是通过哪些方面
- **追问方向**：响应式优化、虚拟 DOM 优化、Tree-shaking、编译时优化

### 场景题：React 状态设计避免不必要的 re-render
- **描述**：如何设计 state 才能避免不必要的 re-render
- **追问方向**：状态提升、状态拆分、React.memo、useMemo/useCallback

### 场景题：页面整体性能优化方案
- **描述**：做过哪些性能优化手段（页面整体方面的）
- **追问方向**：首屏优化、资源优化、运行时优化、构建优化
